- 20% 严格阈值、同周期去重、25% 两次读取后清除角标。

## 兼容性边界

当前公开扩展面没有提供宠物 DOM hit region 或原生事件订阅。Codex 客户端会把官方宠物的开启状态和逻辑桌面坐标写入 `.codex-global-state.json`；当前版本只读这些 `electron-avatar-overlay-*` 字段，不修改 WindowsApps 中的已签名客户端资源。旧结构含精确的 `mascot` 子矩形；当前客户端只保存浮窗原点，因此按官方 110×110 逻辑像素浮窗范围命中，并根据系统 DPI 转换为物理像素。

如果未来客户端不再写入这些字段，才回退到光标周围 112×112 像素的内存识别。回退路径不会保存截图；白色菜单也已排除，避免右键才误触发。

额度 App Server 在程序启动时不会创建。只有宠物交互识别连续命中，才显示胶囊条并启动读取；交互结束后自动隐藏。

## 数据与隐私

持久化目录为 `%LOCALAPPDATA%\CodexPetQuota`。不保存令牌、Cookie、邮箱或原始账户响应；作用域由本机随机盐摘要生成。额度查询不会发送 `turn/start`。
